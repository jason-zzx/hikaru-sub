# 增强时间轴打轴能力

## Goal

提升编辑页中 Subtitle Cue 的打轴效率，使用户能够通过数值平移、整体拖动、边界吸附和波形区间框选完成常见时间调整，同时保持现有多泳道、缩放、边界拖动与项目撤销/重做语义。

## Background

- `src/components/editor/Timeline.tsx` 已支持波形、缩放、多泳道，以及拖动 Subtitle Cue 的开始/结束边界。
- 当前点击 Subtitle Cue 主体主要用于选中和跳转，不能保持持续时间地整体拖动。
- 当前没有统一的边界吸附，也没有批量时间平移入口。
- 字幕列表右键菜单已经约定：右键命中已选行时保留整组选择，命中未选行时仅选择该行；平移命令沿用该范围语义。
- 编辑器对 Subtitle Cue 的持久修改必须进入共享 `projectStore` 撤销/重做历史；拖动过程可以只预览，结束时再写入一次历史。
- 前端已有视频时长和探测帧率；帧率缺失时现有帧步进按 30 FPS 回退，无需新增后端契约。

## Requirements

### R1 - 数值平移

- 在编辑页字幕相关右键菜单中增加“平移时间轴”命令，触发一个选项框。
- 平移量支持按时间或按帧数输入，并支持延后或提前。
- 平移目标支持同时调整开始与结束时间、仅开始时间、仅结束时间。
- 平移命令作用于右键菜单快照的选择范围；每条 Subtitle Cue 都应用用户输入的完整平移量，不因其他选中项触碰边界而缩减整组平移量。
- 提前后小于 `0` 的被调整时间值独立归零；其他时间值和其他 Subtitle Cue 仍应用完整平移量。
- 延后超过视频结束时间时不截断到视频时长。
- 仅调整单侧边界时，若目标边界会越过另一侧，则截断到另一侧边界并允许形成零时长 Subtitle Cue；不得交换边界、跳过该条或拒绝整次操作。
- 一次确认只产生一个项目历史命令。

### R2 - Subtitle Cue 整体拖动

- 在时间轴上拖动 Subtitle Cue 主体时，同时移动开始和结束时间并保持持续时间不变。
- 主体拖动只移动命中的单条 Subtitle Cue；即使该条原本处于多选范围内，也在开始拖动时将选择收敛为该条。
- 整体拖动不得越过视频时间范围；若 Subtitle Cue 自身持续时间已经大于视频时长，则主体拖动为无操作，不缩短字幕。
- 拖动过程只提供预览；拖动结束后一次性写入项目历史。

### R3 - 时间吸附

- 时间轴拖动支持吸附到播放头、相邻 Subtitle Cue 的边界和视频帧。
- 吸附同时适用于边界拖动、主体整体拖动和波形区间框选。
- 主体整体拖动让开始和结束边界同时参与吸附，选择所需位移绝对值最小的结果，再整体应用该位移并保持持续时间。
- 吸附阈值按屏幕像素计算，使不同缩放级别下的操作距离保持一致；播放头和相邻字幕边界使用 12px 强吸附范围，视频帧使用 4px 精细吸附范围。合法强候选进入范围后优先于更近的视频帧候选；吸附不得破坏合法时间范围。
- 相邻字幕候选取其他所有 Subtitle Cue 的开始/结束边界，不依赖会动态重排的视觉泳道。
- 视频帧按当前探测 FPS 的固定帧起点计算，FPS 缺失时沿用 30 FPS 回退；现有播放头帧步进仍使用帧中心，两种语义互不替换。可变帧率逐帧映射不在本任务范围内。

### R4 - 波形区间框选

- 在波形图空白区域拖动时，将拖动范围设置为当前活动 Subtitle Cue 的开始和结束时间。
- 波形框选开始时把多选收敛为活动 Subtitle Cue 单选，只更新这一条。
- 框选范围支持与其他时间轴拖动相同的吸附目标。
- 没有当前选中 Subtitle Cue 时，不修改字幕文档。
- 一次框选只产生一个项目历史命令。

### R5 - 兼容性

- 保留现有点击选中、点击定位播放头、跳转、缩放、多泳道和边界拖动行为。
- 时间轴交互或平移命令修改 Subtitle Cue、切换活动行前，须先提交右侧编辑器中尚未落入项目历史的时间输入草稿，避免静默覆盖；右键命中未选行和时间轴主体单击均须在切换活动行之前提交旧活动行草稿。
- “平移时间轴”对话框打开期间不得响应全局编辑器文档快捷键，避免从模态框背后修改字幕。
- 不新增第三方依赖，不改变 ASS Document、Subtitle Cue 或 Tauri 后端契约。

### R6 - 全局项目历史响应

- 时间轴主体拖动、波形框选和字幕正文编辑完成后，项目历史必须立即可由 `Ctrl+Z` 撤销、由 `Ctrl+Y` / `Ctrl+Shift+Z` 重做，不需要先点击其他区域。
- SubtitleEditor 只在用户实际修改时间输入后提交时间草稿；Store 的同步外部更新时间不得被尚未刷新的本地受控值反向覆盖；同一事件内提交草稿并撤销后，受控时间输入必须显示最终 Store 值。
- 字幕正文和开始/结束时间输入使用项目历史；搜索、字体、快速格式参数等未标记瞬态输入继续使用浏览器/WebView 原生撤销。

## Acceptance Criteria

- [x] 用户可从字幕右键菜单打开“平移时间轴”选项框，并按时间/帧数、提前/延后、开始+结束/仅开始/仅结束完成平移。
- [x] 多选 Subtitle Cue 可在一次确认中批量平移，且撤销/重做按一次操作恢复或重放全部修改。
- [x] 批量提前时，各个负时间值独立归零且不改变其他项的完整平移量；批量延后允许结果超过视频结束时间。
- [x] 拖动 Subtitle Cue 主体会收敛为单选、只移动命中的单条、保持其持续时间，预览连续，释放后只写入一次历史；持续时间大于视频时长时不移动。
- [x] 边界拖动、主体拖动和波形区间框选均可吸附到播放头、相邻字幕边界和视频帧起点；主体拖动由开始/结束边界中所需位移较小的一侧吸附。
- [x] 播放头和字幕边界在 12px 范围内优先于视频帧，视频帧只在无强候选时使用 4px 范围，三类手势均保持该层级。
- [x] 波形空白区域拖动会收敛为活动 Subtitle Cue 单选，并可一次更新其完整时间范围；无选中项时不修改文档。
- [x] 时间轴拖拽被限制在视频范围内；数值平移只限制负时间并允许超过视频结束时间。所有操作保持 `startMs <= endMs`，且单侧平移越界时截断为零时长而不交换边界。
- [x] 现有时间轴选择、点击定位播放头、跳转、缩放、多泳道及边界拖动无回归，且外部时间修改不会覆盖未提交的时间输入草稿。
- [x] 相关单元/组件测试、`pnpm test` 和 `pnpm build` 通过。
- [x] 时间轴主体拖动、波形框选和字幕正文编辑后可立即执行项目撤销/重做，不会被旧时间输入伪草稿吞掉第一次撤销；真实时间草稿被撤销后输入框与 Store 保持一致。
- [x] 时间轴主体单击切换活动字幕不会丢弃旧时间草稿，平移对话框打开期间不会在背后触发全局编辑器文档快捷键。

## Out of Scope

- 自动避让或消除 Subtitle Cue 重叠。
- 磁性开关、吸附目标自定义、吸附强度设置或临时绕过快捷键。
- 新增全局帧率设置、时间码格式或后端媒体探测能力。
- 波形区域新建或删除 Subtitle Cue。
