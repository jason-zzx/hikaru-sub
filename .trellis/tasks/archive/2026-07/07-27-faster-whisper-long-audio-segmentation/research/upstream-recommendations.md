## What Is Actually Upstream Default

OpenAI Whisper and ordinary faster-whisper both default to:

```text
condition_on_previous_text = true
word_timestamps = false
```

Both document the same trade-off: disabling previous-text conditioning can reduce repetition loops or timestamp desynchronization, but may make text inconsistent across windows. This is an option trade-off, not a universal recommendation to disable it.

Ordinary faster-whisper also defaults `vad_filter=false`. Its README describes VAD as opt-in and says the default VAD behavior is conservative, removing silence longer than two seconds.

Neither OpenAI Whisper nor faster-whisper prescribes a fixed subtitle duration or character-count limit. The standard Python examples iterate model-produced `segments`; word timestamps are an optional alignment feature.

## XXL Reference Behavior

The reference SRT was generated by Faster-Whisper-XXL `1.1.1` with `large-v2`.

The locally installed XXL identifies itself as `1.1.1` and reports these relevant defaults:

```text
condition_on_previous_text = true
word_timestamps = true
vad_filter = true
vad_threshold = 0.45
vad_min_speech_duration_ms = 250
vad_min_silence_duration_ms = 3000
vad_speech_pad_ms = 900
sentence = false
standard = false
standard_asia = false
```

The SRT is a useful external text/timing comparison, but not a byte-equivalent
inference baseline or cue-grouping oracle.

XXL publicly exposes optional `--sentence` and `--standard` formatters, but they are disabled by its reported defaults. Public reports still demonstrate why this task should not emulate them: sentence mode can split names or abbreviations, and line-width controls deliberately replace raw grouping.

## Local Upstream-Default Experiment

A 15-minute clip from the private corpus was transcribed with the ordinary upstream defaults relevant to grouping:

```text
vad_filter = false
condition_on_previous_text = true
word_timestamps = false
```

Result:

```text
segments = 609
first 11:52 median duration = 1.0s
first 11:52 P90 duration = 1.0s
first 11:52 median visible chars = 6
fallback temperatures = 0.0, 0.2, 0.8
```

The no-VAD path fragmented much of the speech into one-second segments and hallucinated text during long silence, including a 27-second subscription-message segment. It is not suitable for this source even though VAD-off is the library default.

## Planning Conclusion

Use upstream grouping semantics, not upstream defaults blindly:

- retain previous-text conditioning;
- retain project VAD for this source class;
- do not emulate XXL sentence formatting;
- obtain alignment only to split a raw segment when it demonstrably bridges a long VAD-removed interval;
- otherwise preserve the raw segment one-to-one.

The XXL reference is sufficient for implementation planning when validation
treats it as an external comparison rather than a byte-equivalent baseline.
