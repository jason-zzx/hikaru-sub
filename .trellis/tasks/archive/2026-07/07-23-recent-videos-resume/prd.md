# PRD：最近工作视频与首页续接

## 背景

- `WelcomeView.tsx` 是静态四张入口卡片，打开应用后没有任何"接着上次干"的入口。
- `uiStore` / `projectStore` 均为内存态，无最近视频列表、上次步骤记录。
- 现有可复用能力：
  - 打开视频流程（`ImportView.handleSelectVideo`）：未保存确认 → `prepareVideoSession` → 同目录 `*.translated.ass` / `*.transcribed.ass` 自动加载 → 字幕恢复快照处理。
  - 外部字幕导入（`EditorView.handleSelectSubtitleFile` + `src/utils/subtitleImport.ts` 的 `parseExternalSubtitleDocument`）：已支持 ASS **和 SRT**。
  - `pathExists` / `loadAssText` 等 Tauri 封装齐备。

## 需求

1. **最近列表持久化**
   - 记录最近 10 个 Working Video：视频路径、派生的 transcribed/translated ASS 路径、最近打开时间。
   - 按视频路径去重，MRU 在前；每次成功打开视频即记录。
2. **首页最近列表**
   - WelcomeView 在现有四卡片下方展示"最近打开"：文件名、较小较浅且可截断的父目录路径、相对时间、是否存在转录/翻译字幕（徽标）。
   - 点击条目 → 复用现有打开流程（含未保存确认、同目录字幕自动加载、恢复快照处理），完成后跳转到合适步骤（加载到字幕 → 编辑器；没有字幕 → 转录页）。
   - 单条可移除；视频文件已不存在时给出明确提示，不静默失败。
3. **当前会话续接入口**
   - 会话存在且处于首页时，显示"继续当前工作"卡片：视频名 + `继续编辑` / `继续翻译` / `开始压制` 按钮。
   - 按钮可见性按当前文档与对应文件存在性门控：翻译 ← `transcribed.ass` 存在；压制 ← `translated.ass` 存在；编辑 ← 已加载字幕文档或任一字幕文件存在。仅磁盘字幕存在时，点击“继续编辑”须先复用打开流程载入文档；无字幕时显示“开始转录”。
4. **全局拖放**
   - 拖入视频文件 → 同"打开视频"流程。
   - 拖入 ASS/SRT → 当前有会话时复用编辑器外部字幕导入逻辑并跳到编辑器；无会话时提示先导入视频。
   - 多文件拖入只取第一个可识别文件。
5. **明确不做**：完整项目管理系统、项目文件格式、跨机器同步、最近列表的设置页管理 UI。

## 验收标准

- [x] 通过导入页 / 最近列表 / 拖放任一方式成功打开视频后，最近列表更新并在应用重启后保留。
- [x] 首页最近列表的转录/翻译徽标与同目录 ASS 文件实际存在性一致。
- [x] 当前会话存在时首页出现续接卡片，按钮可见性与对应 ASS 文件存在性一致，点击只跳转步骤、不重开视频；磁盘字幕未载入时会先加载。
- [x] 拖放视频触发未保存确认与同目录字幕自动加载；拖放 ASS/SRT 在无会话时提示、有会话时载入为当前文档（脏状态）并选中首条 cue。
- [x] `pnpm test` 与 `pnpm build` 通过。

自动化验证覆盖了 Tauri 事件回调、监听清理、恢复路由和 localStorage 行为；未进行真实桌面窗口拖放与应用重启后的人工验收。
